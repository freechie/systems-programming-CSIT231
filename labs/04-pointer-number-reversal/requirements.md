# Lab 04 requirements: pointer-based number reversal

> Paraphrased from archived course instructions. This describes the assignment,
> not a claim that the archived submission satisfies every requirement.

## Goal

Repeat Lab 03 while demonstrating pointer and pointer-to-pointer operations.

## Required behavior

1. Preserve all Lab 03 behavior: validation, reversal, digit sum, and the sum of
   the original and reversed numbers.
2. Perform every mathematical operation through a pointer to the variable that
   received the original number; do not use that variable directly in the math.
3. Print both calculated sums through pointer-to-pointer expressions.
4. After all calculations and result output, print the memory address of every
   variable, including all pointer variables.

The printed addresses are expected to vary between executions.
