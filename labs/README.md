# Lab archive

The lab directories pair each archived submission with a concise, paraphrased
summary of its original requirements. The summaries were reconstructed from
privately retained Fall 2022 course materials; the instructor's original prompt
wording and example programs are not reproduced here.

The requirement summaries describe the assignments, not necessarily the
behavior achieved by the submitted source code.

## Archive policy

- Submission source is retained with only the narrow maintenance changes
  documented in the repository's main README.
- Requirement summaries use original wording only where a filename, literal
  output value, or API name is technically significant.
- Instructor examples, full assignment prompts, compiled executables, course
  infrastructure details, and credentials are excluded.
